# 一次函数单线教学图模型设计

## 目标

把当前一次函数图形组件从固定演示图改造成由学习任务驱动的单线教学组件，确保题干、条件、给定点、直线、截距、viewport 和教学反馈使用同一事实来源。

本切片只交付单线教学。双方案比较、第二条直线及真实交点进入下一独立切片。

## 当前问题

当前任务要求直线经过 `(2, 3)` 和 `(0, -1)`，但图组件初始主线为 `y = x - 1`，同时显示没有题目来源的 `y = -x + 5` 参考线，并把 `(2, 3)` 标为交点。完全不可见的直线还会被绘制成边界水平线，越界截距会被夹到边界后继续冒充真实 `(0, b)`。

这些问题会向学生展示错误的数学证据，必须通过统一模型解决，而不是只修改若干 SVG 坐标。

## 方案选择

采用“本地 lesson registry + 单线图模型”。

- 不采用仅给图组件增加零散 props：页面题干、教练文案和图形仍可能漂移。
- 暂不采用后端下发完整 lesson payload：这会扩展内容审核、API 和数据管线，超出当前切片。
- 本地 registry 后续可替换为审核后的内容 API，而不重写图组件。

## 数据模型

```ts
export type GraphViewport = {
  xMin: number;
  xMax: number;
  yMin: number;
  yMax: number;
};

export type LinearEquation = {
  k: number;
  b: number;
};

export type GraphPoint = {
  id: string;
  label: string;
  x: number;
  y: number;
  role: "given" | "target";
};

export type LinearFunctionGraphModel = {
  initialLine: LinearEquation;
  viewport: GraphViewport;
  givenPoints: GraphPoint[];
};

export type LinearFunctionLesson = {
  taskId: string;
  title: string;
  prompt: string;
  conditions: string[];
  goals: string[];
  graph: LinearFunctionGraphModel;
};
```

lesson registry 以 `taskId` 查找受控本地模型。未知任务不得回退到不相干的数学条件；应显示明确的“该任务的交互图尚未配置”状态，并保留返回今日任务的路径。

当前 `task-linear-kb` lesson 使用：

- 给定点 `(2, 3)` 与 `(0, -1)`。
- 初始探索线 `y = x - 1`，表示学生尚未调到目标。
- 目标是通过 `(0, -1)` 识别 `b = -1`，再由 `(2, 3)` 得到 `k = 2`。
- 单线模式，不显示参考线、交点或方案比较文案。

## 组件职责

`LinearFunctionTaskPage` 根据任务 ID 读取 lesson，并从同一 lesson 渲染题干、条件、目标和图组件。

`LinearFunctionGraph` 接收 `model`，内部只管理当前 `k/b` 探索状态：

- 初始化或任务切换时重置为 `model.initialLine`。
- 主线、给定点、图例和 viewport 全部来自模型或数学推导。
- 不接受自由文本公式、交点标签或第二条线。
- 不包含任务页教练文案和报告数据。

几何计算应从 React 渲染中分离为可单测纯函数：

- 计算直线与 viewport 的可见线段。
- 判断截距是否真实可见。
- 判断给定点是否在当前直线上。
- 对完全不可见的直线返回 `null`，不得生成伪水平线。

## 教学交互

### `k` 探索

- 支持正数、零、负数和一位小数。
- 修改后实时同步公式和直线。
- 展示上升、水平或下降状态。
- 解释“x 每增加 1，y 改变 k”；比较绝对值时说明更陡或更缓。

### `b` 探索

- 修改后实时平行移动直线。
- 解释 `x = 0` 时 `y = b`，把截距与初始量联系起来。
- `(0, b)` 只在真实可见时绘制；越界时仅用文本说明方向和真实数值。

### 点判断

- 给定点必须来自 lesson。
- 学生可选择一个给定点执行“是否在线”判断。
- 反馈展示实际点的 `y` 与代入 `kx+b` 得到的值，而不是只显示对错。
- 点角色不得暗示交点；本切片只使用“给定点/目标点”。

### 控件

- 保留精确 number 输入；若后续增加 range，必须与 number 同步，不在本切片强制引入。
- 增加重置按钮，恢复 lesson 初始状态。
- 移除没有真实行为的“放大”按钮。
- “显示网格”只有实现真实显隐后才能保留；否则本切片移除。

## 状态与错误处理

- 空输入、非有限数字或超出约定范围时保留最后有效图形，并显示输入提示，不能向 SVG 传入 `NaN`。
- 完全不可见时显示“当前直线超出可视范围”，仍保留公式和重置操作。
- 截距越界时不绘制伪造点。
- lesson 缺失或数据无效时不绘制图形，不编造默认条件。
- 任务切换必须重置当前 `k/b`、点判断结果和观察反馈。

## 可访问性

- `k/b`、重置和点判断均可用键盘操作，并具有可见标签和焦点样式。
- SVG 提供动态文本替代，包含当前公式、趋势、截距可见状态和给定点列表。
- 参数变化通过简短 `aria-live` 文本播报，不依赖颜色表达上升/下降或点判断结果。
- 给定点同时在旁侧文本列表显示；颜色不是唯一识别方式。
- 390px 宽度下公式、图形、控件和反馈不得造成页面横向溢出。

## 测试与验收

### 几何纯函数

- 正斜率、负斜率和水平相交线。
- 完全不可见的水平线返回 `null`。
- 角点相切和浮点容差。
- 截距可见/不可见。
- 给定点在线/不在线。

### 组件

- 所有点和 viewport 来自 model。
- 本切片不渲染参考线、交点或方案比较文案。
- `k/b` 改变后公式、趋势和截距反馈同步。
- 越界不绘制伪造线段或截距点。
- 重置恢复初始值。
- 输入错误保留最后有效图。

### 页面

- 题干、条件、目标和图形来自同一 lesson。
- `task-linear-kb` 只呈现单线语义。
- 未知 task 显示明确不可用状态。
- 任务切换重置图形状态。

### 回归

- 学生端完整测试、lint、build 通过。
- 现有学习任务、练习、报告和内容渲染流程不回归。
- 独立验证和代码审查不得由实现 Agent 代替。

## 明确排除

- 第二条直线、双方案比较、交点、平行和重合判断。
- 自由缩放和平移、无限画布。
- 拖拽点、自由作图和自动批改。
- 后端 lesson API、内容审核 Schema 扩展。
- 二次函数、任意函数和复杂几何。
- 原型目录的同步重构；生产组件完成后另行决定原型是否冻结。
