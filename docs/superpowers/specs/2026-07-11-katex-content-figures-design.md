# 受控公式与题图渲染设计

## 背景

学生端已有 `ControlledContentRenderer`，能够把已审核内容单元中的有限 Markdown 转成 React 元素，并拒绝外链、协议相对 URL 和原生 HTML。当前公式仍以 TeX 原文显示，示例题图文件也不存在，因此尚未形成可用于数学学习的真实渲染闭环。

本设计只增强一次函数任务页的公式和题图展示。教材资料用于校准真实内容的公式形态、图文比例和失败场景，不直接把教材整页或原始题图复制进仓库。

## 目标

1. 使用 KaTeX 正确排版行内公式和块级公式。
2. 保留现有有限 Markdown 白名单和 React 文本转义边界。
3. 只加载固定公开目录中的同源题图。
4. 题图加载失败时显示可理解的降级内容。
5. 在桌面和移动端保持长公式可读、题图不溢出。
6. 用自制一次函数样例跑通 API 内容、任务页和静态题图的闭环。

## 非目标

- 不实现教材批量导入、OCR、版面分析或题目切分。
- 不建立结构化资产 ID、对象存储或 CDN。
- 不修改题图审核、图形识别或置信度数据模型。
- 不扩展完整 CommonMark、GFM、表格、链接、引用、代码块或嵌套列表。
- 不直接发布或复制 `E:\初中\教材` 中的教材整页和原始题图。
- 不统一本切片之外的 `approved` 与 `published` 状态语义。

## 方案选择

### 采用方案

保留现有手写白名单解析器，只把数学节点交给 KaTeX，并把图片来源收紧到 `/images/content/`。该方案复用当前安全模型，改动集中，适合作为可独立验证的小切片。

### 暂不采用

- 完整 Markdown 渲染库：可扩展性更好，但会扩大依赖、HTML 清洗和节点白名单的审查范围。
- 结构化资产系统：更接近生产方案，但需要同时修改 API DTO、持久化、后台审核和发布流程，应作为后续独立切片。

## 内容语法

继续支持以下语法：

- `##`、`###` 标题。
- 普通段落。
- `-`、`*` 开头的单层无序列表。
- `**粗体**` 和行内代码。
- `$...$` 行内公式。
- 独占一行或由成对 `$$` 包围的块级公式。
- 独占一行的 `![替代文本](/images/content/file.png)`。

其他 Markdown 语法均按普通文本处理或忽略，不生成原生 HTML。

## 公式渲染

新增内部 `MathExpression` 组件，输入为公式字符串和显示模式：

- 使用 KaTeX `renderToString` 生成数学排版。
- 固定 `throwOnError: true`、`trust: false`、`strict: "error"`，由组件捕获语法或受限命令错误。
- 单条公式最多 2,000 个字符，并限制 KaTeX 宏展开次数；超过限制时直接进入文本降级。
- 成功时只注入 KaTeX 生成的受信 HTML，不接受内容 Markdown 中的 HTML。
- 失败时显示原始公式文本，并附加“公式暂时无法显示”的无障碍说明，不能让整段内容崩溃。
- 行内公式保持随正文换行；块级长公式容器允许横向滚动。

KaTeX 样式在学生端入口统一引入，避免组件重复加载样式。

## 题图策略

允许的图片路径必须满足：

1. 以 `/images/content/` 开头。
2. 文件名只包含 ASCII 字母、数字、短横线、下划线和单个扩展名分隔点。
3. 扩展名仅允许 `.png`、`.jpg`、`.jpeg` 或 `.webp`，大小写不敏感。
4. 不允许子目录、反斜杠、查询参数、片段、百分号编码或路径穿越片段。

首个样例资源使用项目自制的一次函数坐标图，保存为：

`apps/student-web/public/images/content/linear-kb-concept.png`

图片使用 Markdown 提供的替代文本。加载失败后隐藏破损图片并显示带相同替代文本的占位区域；该状态保留在当前组件实例中，不发起自动重试。

这只是静态发布目录门禁，不代表资产已经具备独立审核状态。后续必须用结构化 `assetId` 和学生端资产 DTO 替换自由文本路径。

## 数据流

1. API 继续只从学习包编排中返回 `reviewStatus === "approved"` 的内容单元。
2. 内置一次函数内容把示例图片引用改为 `/images/content/linear-kb-concept.png`。
3. 学生端学习包服务保持现有契约，把 `contentMarkdown` 交给任务页。
4. `ControlledContentRenderer` 解析白名单块和行内节点。
5. 数学节点由 KaTeX 渲染，图片节点先验证路径再加载。
6. 非法公式和加载失败图片在局部降级，不影响其余学习内容。

## 教材样本使用

真实样本取自 `E:\初中\教材\markdown\人教版八年级数学下册.md` 的第十九章“一次函数”，只用于确认以下形态：

- 一次函数与分段函数表达式。
- 坐标图和正文的组合关系。
- OCR 后可能出现的全角字符、空格和不规范 TeX。
- 大尺寸分页图在移动端的比例风险。

实现和测试使用重新编写的短文本、公式与自制坐标图，不把教材原文、整页 PNG 或扫描页提交到仓库。

## 错误处理

- 非法 Markdown 图片路径：不渲染图片，也不发起网络请求。
- KaTeX 语法错误：显示原始表达式和可访问的错误说明。
- 图片网络或静态资源失败：显示题图占位和替代文本。
- 其他 Markdown：作为文本处理，保持 React 默认转义。

本切片不在 UI 中暴露技术错误、路径规则或 KaTeX 名称。

## 测试策略

### 组件测试

- 行内与块级公式生成 KaTeX DOM。
- 分式、根式、上下标正常渲染。
- 非法公式局部降级且其余内容继续显示。
- 超长公式和受限 KaTeX 命令进入文本降级。
- 仅接受固定目录和允许扩展名。
- 拒绝外链、协议相对 URL、路径穿越、反斜杠、查询参数、片段和编码路径。
- 图片 `error` 事件触发占位状态。
- HTML 继续作为文本显示，不产生脚本节点。

### 集成测试

- 一次函数任务页能从学习包渲染 KaTeX 公式和规范题图路径。
- API 内置内容只引用固定公开目录。
- 已有“仅返回已审核内容”测试继续通过。

### 浏览器验证

- 启动 API 与学生端，在真实浏览器中确认图片请求返回成功。
- 桌面和窄屏视口确认长公式不挤压布局，题图不超出内容区域。
- 人工触发缺失图片，确认占位不会导致页面跳动或按钮遮挡。

## 验收标准

- `$y = kx + b$`、分式、根式和上下标以数学排版显示，而不是 TeX 原文。
- 一条非法公式不会阻断同一内容单元的其他内容。
- 只有 `/images/content/<安全文件名>` 形式的题图会生成图片请求。
- 自制一次函数题图在任务页真实加载成功。
- 题图加载失败时显示替代文本占位，不出现浏览器破图。
- 桌面和移动端均无公式、题图或相邻控件溢出和遮挡。
- 学生端测试、lint、build，API 测试和 build 全部通过。
